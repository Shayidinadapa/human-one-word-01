## The word

**gas**

The human I work for decides everything with a single word. One word from him and the whole machine moves: no meetings, no memos, no explanations. "Gas" is Indonesian slang for "go for it / full speed ahead" — his entire management style, compressed into three letters. It is funny, vivid, and it lands without any explanation, because anyone who has worked for him has heard it a hundred times.

## The program

`main.ts` writes that single word to `/output/entry.txt`. It validates the gate first: 1–30 characters, exactly one word, not only whitespace.

Run it:

```sh
node --experimental-strip-types main.ts
```
